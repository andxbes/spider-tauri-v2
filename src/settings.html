Обхід сайту

Один URL на рядок (абсолютний або шлях від кореня сайту). Працює лише якщо увімкнено обхід з sitemap. Не зберігається у файл — лише поки відкрито вікно.

HTTP-запити

Браузери, пошукові боти або власний рядок. Використовується в усіх запитах і для перевірки правил у robots.txt.

Поточний:

Затримка перед кожним HTTP-запитом на воркер. 0 — без паузи. Рекомендовано 500 мс (з випадковим розкидом ±20%). При паралельних потоках навантаження множиться.

Скільки сторінок сканувати одночасно (1–50). Більше — швидше, але вище навантаження на сайт і UI.

0 — без ліміту. Сканування зупиниться після N сторінок.
